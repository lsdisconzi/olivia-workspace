Meshy AI — Generowanie 3D

              
            

            

              Użyj agenta, aby wygenerować teksturowane siatki 3D, remesh/rig lub zaimportować istniejący model Meshy. Agent wywoła oficjalne narzędzia MCP (create_*, retrieve_*, stream_*) i zwróci URL GLB — kliknij Importuj na kafelku, który pojawi się w HUD 3D.
            


            

              
              
              
            


            
            

              
              
              

                
                
                
              

            


            
            

              
              
              
              
              

                
                
              

            


            
            

              
              
              
              
              
Agent wywoła retrieve_*_task, poczeka na status=SUCCEEDED i zwróci URL GLB do zaimportowania.
              

            


            

              

              
              
            


            

              ⓘ Każde generowanie zużywa kredyty z Twojego konta Meshy. Klucz MESHY_API_KEY jest odczytywany z OliviaLegal/.env i pozostaje na hoście — interfejs nie wykonuje bezpośrednich wywołań do Meshy.
