              Use the agent to generate textured 3D meshes, remesh/rig, or import an existing Meshy model. The agent will call the official MCP tools (create_*, retrieve_*, stream_*) and return the GLB URL — click Import on the chip that appears in the 3D HUD.

              ⓘ Each generation consumes credits from your Meshy account. The MESHY_API_KEY is read from OliviaLegal/.env and stays on the host — the UI does not make direct calls to Meshy.
