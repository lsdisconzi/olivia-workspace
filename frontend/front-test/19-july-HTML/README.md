# Olivia · Havan — Uma Chance para Fazer o Bem

Site estático auto-contido, pronto para deploy na Netlify.

## Conteúdo
- `index.html` — landing page (português BR, identidade Havan, paleta verde/azul/amarelo sem vermelho)
- `outreach/pdf/` — 7 cartas de abordagem personalizadas em PDF
- `netlify.toml` / `_redirects` — config de publicação

## Temas
Botão de paleta no canto inferior direito alterna entre 5 temas da marca Havan
(Verde & Amarelo, Azul Confiança, Verde Floresta, Amarelo Energia, Cinza Estrutura).
A escolha é salva em `localStorage`.

## Deploy
Arraste esta pasta para https://app.netlify.com/drop ou conecte ao repositório.
Nenhuma build necessária (HTML estático).
